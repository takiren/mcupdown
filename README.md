# mcctl
マイクラサーバーを管理するアプリ。

## ターゲット
1ノードでマイクラサーバーを少数管理する人向け。
複数管理したいなら他のクラウドサービス使う方が楽だと思う。

## 実装したい機能
- マイクラサーバーの自動ダウンロード
- ポートを指定してマイクラサーバーを起動
- マイクラのコマンド実行
- コンテナで実行
- 複数コンテナエンジン対応。当面はdockerとpodman

## コンテナ化
rootlessでもrootfulでも動くように作りたい。
デーモンを常駐でいいや。どんなサーバーが動いているかはみんなに見せて良い。
あまり複雑にすると面倒になる。

コンテナの状態管理はファイルかDBに委任する形にする。
プロセス管理だけデーモンに任せて、コンテナは別ユーザーで動かす。
ポスグレとかそんな感じじゃん

簡単なインターフェース切って拡張可能にすればなんとかなるでしょ、知らんけど。

dockerとpodman以外にも対応させるならASTが必要だけど、そこまでやる気はないな。
javaのバージョン管理が面倒だからコンテナ化しないとどこかで詰む。

割と素朴な実装でいいと思う。
中身のイメージ
```go
// 雑だけどイメージ。タグはつけたいけどね。
out,err:=exec.Command("podman", "build").Output()
// or
out,err:=exec.Command("docker", "build").Output()
```
